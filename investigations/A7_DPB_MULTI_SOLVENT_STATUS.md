# A7 DPB multi-solvent-class candidate status

**Status:** INELIGIBLE BEFORE OUTCOME TEST

Amendment A7 preregistered a comparison using directly measured DPB rotational reorientation time as an independent microscopic environment-coupling predictor.

Full-text extraction showed that the available rotational quantity in the source dataset, `zeta_rot`, is explicitly **estimated from solvent viscosity and solvent-solute volume ratio** rather than directly measured by anisotropy/polarization in this paper.

Therefore using it against viscosity would not provide an independent Capital-Chi predictor and would violate the target-independence/feature-independence firewall.

No A7 correlation or predictive model was run.

This is an eligibility failure, not a negative kinetic result.
