# A7 result: metallocene solvent-relaxation test

**System:** Cp'2Co+/0 self-exchange across 11 source-identified Debye solvent conditions.  
**Source:** McManis et al., JACS 1989, DOI 10.1021/ja00197a004.  
**Status:** P1 positive within-couple empirical architecture evidence.

## Frozen variables

Target:
- source barrier-corrected self-exchange rate ratio, k'ex/k'ex(ACN).

Predictor:
- independently characterized inverse longitudinal solvent relaxation ratio, tau_L^-1/tau_L^-1(ACN).

The barrier correction is based on independently measured optical electron-transfer energies. Electronic-coupling values inferred from the target rate dependence are excluded.

## Results

- n = 11 Debye solvent conditions;
- Pearson r = 0.9525883;
- Spearman rho = 0.8904202;
- leave-one-solvent-out intercept-only MSE = 1.6584745;
- leave-one-solvent-out tau_L model MSE = 0.1883973;
- Delta MSE = +1.4700773;
- full-series log-log slope = 0.7978337.

## Interpretation

This is the first positive empirical result in the Capital-Chi rate pilot under the frozen non-circular rules.

It supports the bounded statement:

> After independent correction for solvent-dependent barrier variation, an independently measured environmental dynamical descriptor carries substantial predictive information about kinetic variation within this metallocene self-exchange system.

It does not establish:
- a scalarized Capital Chi;
- an absolute cross-reaction rate law;
- P2 cross-family prediction;
- replacement of electron-transfer theory.

## Required next step

Repeat the same frozen analysis for additional metallocene couples only where the source table permits unambiguous extraction of at least five Debye-solvent pairs. Retain expected null/weak cases, because the source reports diminishing solvent-dynamical control for less facile couples. The cross-couple pattern is a test of rate-regime classification, not an opportunity to select only the positive couple.
